Какво прави проектът?

Програмата представлява интерактивна уеб игра „Морски шах“, в която потребителят играе срещу компютърен противник в браузъра. Ботът решава проблема с намирането на най-добрия възможен ход във всяка ситуация, като използва алгоритъма Minimax с алфа-бета отсичане, което го прави непобедим при оптимална игра. При всяка нова партия ролите (X и O) се разпределят на случаен принцип, а резултатът се следи в реално време.

Как се стартира програмата?

Инсталирайте нужните библиотеки:

pip install gradio


Стартирайте основния файл:

python main.py


(След стартиране отворете локалния линк http://127.0.0.1:7860/ или генерирания публичен .gradio.live адрес в браузъра си.)

Съдържание на хранилището

main.py – изходен код на играта, алгоритъма Minimax и уеб интерфейса

requirements.txt – списък с необходимите външни библиотеки (gradio)

Pismena_Teoria.pdf – писмена теория и анализ за защитата
