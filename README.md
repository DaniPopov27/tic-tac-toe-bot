Морски шах (Tic-Tac-Toe) с алгоритъм Minimax

Интерактивна уеб версия на класическата игра „Морски шах“, разработена на Python с библиотеката Gradio. Компютърният противник използва алгоритъма Minimax с Алфа-Бета отсичане, което му позволява да анализира всички възможни ходове и да играе оптимално.

Основни функционалности

Оптимална логика на игра (Minimax + Alpha-Beta Pruning): Ботът преценява всички бъдещи комбинации и избира най-добрия възможен ход, съобразявайки се с дълбочината на хода (depth).

Случайно разпределение на ролите: При всяка нова игра програмата избира на случаен принцип кой ще играе със символ X (започва пръв) и кой със символ O.

Модерен уеб интерфейс: Тъмен дизайн (Dark Mode) с 3×3 мрежа от интерактивни бутони, изграден чрез Gradio и персонализиран CSS.

Табло с резултати (Scoreboard): Проследява победите на играча, равенствата и победите на бота по време на сесията.

Възможност за онлайн тестване: Поддържа генериране на публичен уеб линк чрез share=True, докато приложението работи.

Използвани технологии

Python 3

Gradio – за изграждане на уеб интерфейса

HTML / CSS – за стилово оформяне на таблото и статус банерите

Вградени модули: math, random

Инсталиране и стартиране

1. Изисквания

Уверете се, че имате инсталиран Python 3.8 или по-нова версия.

2. Инсталиране на необходимата библиотека

Отворете терминала (в PyCharm или командния ред) в папката на проекта и изпълнете:

pip install gradio


3. Стартиране на играта

Изпълнете основния файл main.py:

python main.py


След стартиране в конзолата ще се появи локален адрес (обикновено http://127.0.0.1:7860/), който можете да отворите във всеки уеб браузър.

Структура на проекта

tic tac toe bot/
├── main.py             # Основен код с логиката на играта, Minimax и уеб интерфейса
├── requirements.txt    # Необходими външни библиотеки (gradio)

(Забележка: Ако качвате проекта в GitHub, създайте файл requirements.txt и запишете в него думата gradio, за да може всеки лесно да инсталира зависимостта.)
